# ВАКУУМ — сервис доставки здорового питания

Веб-приложение для подбора рациона и заказа готового питания на несколько дней. Пользователь может рассчитать ориентировочную калорийность, посмотреть меню и его состав, настроить ограничения по питанию и оформить заказ.

## Возможности

- Калькулятор ориентировочной нормы калорий и КБЖУ.
- Меню с выбором цели, калорийности и длительности рациона.
- Фильтры по типу питания и аллергенам.
- Расчёт стоимости и скидки в зависимости от длительности заказа.
- Оформление заказа с выбором адреса, даты доставки и способа оплаты.
- Личный кабинет: история заказов, адреса, вес, отзывы и поддержка.
- Административный раздел для работы с заказами, клиентами, меню, отзывами и обращениями.
- Адаптивный интерфейс на русском языке.

> Онлайн-оплата пока не подключена: выбор оплаты картой не запускает платёж, заказ нужно оплатить при получении.

## Запуск локально

### Требования

- Node.js (рекомендуется актуальная LTS-версия)
- npm
- Проект Supabase с настроенной схемой и политиками доступа

1. Склонируйте репозиторий и перейдите в его каталог:

   ```bash
   git clone https://github.com/dobryak-11/green-week.git
   cd green-week
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Создайте в корне проекта файл `.env.local` и укажите ключи своего проекта Supabase:

   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
   ```

   Значения можно найти в настройках проекта Supabase. Используйте только публичный anon/publishable key; секретный `service_role` key нельзя добавлять в переменные `NEXT_PUBLIC_*` или клиентский код.

4. Запустите сервер разработки:

   ```bash
   npm run dev
   ```

5. Откройте [http://localhost:3000](http://localhost:3000).

## Настройка Supabase

Приложение использует Supabase Auth и таблицы `orders`, `profiles`, `addresses`, `weights`, `reviews`, `tickets`, `ticket_messages`, `dishes` и `settings`. Для изображений блюд используется Storage bucket `dishes`, а проверка прав администратора обращается к функции `is_admin`.

Перед полноценной работой настройте эти ресурсы, правила Row Level Security, авторизацию и функцию `is_admin` в своём проекте Supabase. SQL-миграций и готового файла со схемой базы данных в этом репозитории нет. Без настроенного Supabase часть приложения (вход, заказы, личный кабинет и админ-панель) работать не будет.
